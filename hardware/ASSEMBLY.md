# 装配与首板验证

## 贴装顺序

1. 首先不贴 U2/ML307，仅贴 USB 输入、3.3 V LDO、ESP32-C3 及其外围。
2. 限流电源设为 5.0 V/300 mA，确认 `+3V3` 为 3.20–3.40 V，ESP32-C3 USB 能枚举并可烧录。
3. 贴装 SY8205、L1 和 3.8 V 电源外围，继续不贴 U2。GPIO5 拉高后确认 `+3V8_MODEM` 为 3.74–3.89 V；用电子负载从 0.1 A 增加到 2.0 A，检查温升、纹波和瞬态跌落。测试台电源与连接线必须能稳定提供 5 V/2 A。
4. 电源测试通过后贴 ML307A、TXU0202、SIM 与天线网络。LTE MAIN 的串联位 R14 装 0 Ω，C23/C24 暂不贴；GNSS 同理。
5. 首板不要依赖板载天线测试 LTE，J3 必须连接 50 Ω LTE 天线后再开机。

## 必测项目

| 项目 | 测试方法 | 合格条件 |
| --- | --- | --- |
| USB 输入 | 5 V/2 A 电源，测 F1 两端 | 稳态压降小于 120 mV |
| 3.3 V | ESP32-C3 Wi-Fi 连续发包 | 3.20–3.40 V，无复位 |
| 3.8 V | 电子负载 0.1/1/2 A 阶跃 | 不低于 3.4 V；稳态 3.74–3.89 V |
| 硬断电 | 在网页执行模组重启 | GPIO5 低时 U2 VBAT 接近 0 V，高后自动启动 |
| UART | 115200 8N1 执行 `AT`/`ATI` | 连续 100 次无乱码、无超时 |
| SIM | 插卡后执行 `AT+CPIN?`/`AT+ICCID` | READY 且 ICCID 可读 |
| 驻网 | 三家运营商分别测试 | 支持频段与 SIM 策略允许时可注册；记录 PLMN/频段/RSRP |
| 短信 | 上下行各 20 条，含中文长短信 | 无丢失、无重复、转发内容正确 |
| 射频 | 暗室或传导测试 | 按当地法规与运营商认证要求执行 |
| 稳定性 | 24 小时 Wi-Fi + LTE + 短信压力测试 | 无看门狗重启、无模组掉电、无内存持续下降 |

## 量产注意事项

- ML307A 的 UART 为 1.8 V，禁止用 3.3 V USB-TTL 直接连接模组 UART0。
- 模组贴装后不能用热风长时间集中加热底部 LGA；首件应做 X-Ray 或切片抽检。
- U.FL 插拔寿命有限，产测夹具优先使用同轴测试头，不要反复手工拔插。
- `ML307A-DSLN` 和 `ML307A-DCLN` 使用相同 94-pin PCB 版本；是否具有 GNSS 以采购料号和供应商规格为准。
- RF π 网络的 DNP 电容值只能在成品外壳、天线和线缆确定后通过 VNA/射频测试选择。
- Rev 1.0 的 0.38 mm RF 线宽与 0.20/0.20 mm USB 差分名义值必须在下单时按实际 JLC04161H-7628 叠层重新核算，采用工厂给出的阻抗补偿值。
- 首件贴装前在 JLC 的 BOM/CPL 预览中逐项核对极性、Pin 1 与底层器件镜像方向，不应只依赖自动匹配结果。

# SMS Forwarder 局域网发现工具

双击 `sms-forwarder-lan-scanner.exe` 后，工具会自动广播发现请求，并列出同一局域网内的 SMS Forwarder 设备。双击设备或点击“打开管理页面”即可进入管理台。

工具只读取设备 IP、Wi-Fi MAC、设备 ID、固件版本、蜂窝模组型号和 OTA 能力，不读取手机号、ICCID、短信、Wi-Fi 密码或通知密钥。

## 无法发现设备

1. 确认电脑和设备连接到同一路由器或同一个设备配置热点。
2. 关闭路由器的 AP 隔离、访客网络隔离或无线终端隔离。
3. 如果 Windows 防火墙首次询问，请允许工具访问“专用网络”。
4. 旧固件没有发现协议；请先通过 USB 或 OTA 升级到 v1.6.0 及以上版本。

发现协议使用 UDP 37888，只回应同一 IPv4 子网内、格式和随机 nonce 均有效的请求。
